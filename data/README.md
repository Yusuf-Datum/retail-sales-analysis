# Dataset

This folder contains the data used for my retail sales analysis project.

I'll use the dataset to explore sales performance, identify trends, and understand how different products, regions, and customer segments contribute to sales.

Before starting the analysis, I'll check the data for missing values, duplicate records, incorrect dates, and unusual transactions. I'll also document the cleaning process so that the decisions made during the project are clear.

The cleaned data will then be used for further analysis in Excel and for building a dashboard in Power BI.
