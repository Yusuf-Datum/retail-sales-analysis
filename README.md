# Retail Sales Analysis

## Project Overview

This project explores retail sales data to identify sales trends, evaluate product performance, and understand customer purchasing behaviour.

The goal is to turn raw sales data into useful business insights that can support better decision-making.

Objectives

* Analyse overall sales performance.
* Identify the best- and worst-performing products.
* Compare sales across regions and customer segments.
* Examine monthly sales trends and seasonality.
* Investigate data quality issues and document cleaning decisions.
* Develop an interactive dashboard in Power BI.

 Tools & Technologies

* Microsoft Excel — data cleaning and exploratory analysis.
* Microsoft Power BI — data visualisation and dashboard development.
* GitHub — project documentation and version control.

 Project Workflow

1. Data inspection and quality assessment.
2. Data cleaning and documentation.
3. Exploratory data analysis.
4. Dashboard development.
5. Findings and recommendations.
